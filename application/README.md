## Status of the facts in this pack

The regulator's own pages were **not reachable** when this was prepared, so requirements come from
secondary sources (industry bodies, training providers, news) and prior knowledge. Anything marked
**[Verify]** must be confirmed against the current Building and Plumbing Commission (BPC) pages and
the live application form before you spend money or time on it. See `06-verify-with-bpc.md`.

## Regulator note

The Building and Plumbing Commission (BPC) has operated as Victoria's building regulator since
1 July 2025, absorbing the Victorian Building Authority (VBA) functions. Older guides and some forms
still say "VBA". Use the BPC site for current forms. **[Verify]**
