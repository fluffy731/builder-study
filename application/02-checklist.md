# 02 – Master checklist

Tick items as you complete them. `[Verify]` = confirm against the current BPC page/form first.
Mirror state in `tracker.csv` if you prefer a spreadsheet.

## Phase 0 – Eligibility
- [ ] Open the current BPC "Domestic Builder" class page and the DB-U application form; save a dated PDF of each to `07_Application-Submission/`
- [ ] Record the exact qualification requirement for DB-U (codes/levels accepted) **[Verify]**
- [ ] Record the experience requirement: years, recency window, type of work **[Verify]** (secondary sources say ~3 years within the last 7 – unconfirmed)
- [ ] Record the number of projects required (sources conflict: 3 vs 4) **[Verify]**
- [ ] Self-assess each requirement: Met / Gap / Unsure, with evidence reference
- [ ] If any gap: decide RPL/skills assessment, extra experience, or qualification upgrade (see workflow decision rules)
- [ ] Confirm the exam format and booking process for DB-U (online exam replaced interview) **[Verify]**
- [ ] Confirm all fees (application, exam, registration, any insurance assessment) and payment method **[Verify]**

## Phase 1 – Set-up
- [ ] Create OneDrive folder tree (`scripts/make-onedrive-folders.ps1` or `.sh`, or unzip the template)
- [ ] Copy `tracker.csv` and `03-document-register.md` content into `00_Admin-Tracker/`
- [ ] Set a working rule: every file named `YYYY-MM-DD_Description_vN`
- [ ] Turn on OneDrive version history / personal vault for `01_Identity` and `05_Insurance-Financial`

## Phase 2A – Identity and probity
- [ ] Identity documents per BPC point/category requirements, certified where required **[Verify]**
- [ ] Evidence of any name change (marriage/deed poll certificate)
- [ ] Right to work / residency evidence if requested **[Verify]**
- [ ] National criminal history check (check validity window; order only when close to lodging) **[Verify]**
- [ ] Bankruptcy / insolvency search (National Personal Insolvency Index) and any company-director history
- [ ] Disclosure statement: prior disciplinary action, refused/cancelled registration or licence (any jurisdiction), convictions, pending proceedings
- [ ] Statutory declaration(s) if the form requires them (witnessed by an authorised person)
- [ ] "Fit and proper person" self-review: anything that could raise a question is explained in writing, with evidence, *before* lodging

## Phase 2B – Qualifications
- [ ] Certificates/testamurs and academic transcripts for each qualification relied on
- [ ] Statements of attainment for individual units where used
- [ ] RPL / skills assessment outcome letter if applicable
- [ ] Certified copies made as required by the form **[Verify]**
- [ ] Qualification codes on the form match the certificate exactly (including superseded codes and equivalence)

## Phase 2C – Project evidence (repeat per project; use `04-project-evidence-template.md`)
- [ ] Select the strongest projects: recent, domestic, varied in scope, your role clearly senior
- [ ] Project 1 template complete and evidence filed
- [ ] Project 2 template complete and evidence filed
- [ ] Project 3 template complete and evidence filed
- [ ] Project 4 template complete and evidence filed (if 4 are required) **[Verify]**
- [ ] For each: building permit, approved plans/specs, contract or scope, key inspection/certificate evidence, occupancy permit or certificate of final inspection, photos, proof of your role
- [ ] Cross-check each project's dates and values against the application form and the referee brief

## Phase 2D – Technical referee
- [ ] Confirm referee eligibility criteria on the BPC form (registration class, years registered, independence) **[Verify]**
- [ ] Shortlist two candidates; approach with the brief (`05-technical-referee-brief.md`)
- [ ] Agree timeline and how the signed report is delivered/submitted
- [ ] Supply referee with project packs (de-identify client details where appropriate)
- [ ] Referee report received; check it against your own project write-ups for inconsistencies
- [ ] Copy of referee's registration details verified on the public register

## Phase 2E – Insurance and financial
- [ ] Confirm how domestic building insurance eligibility is assessed now that the BPC holds the insurance function **[Verify]**
- [ ] Gather any financial information the assessment needs (personal/business position, ATO status)
- [ ] Confirm whether other insurance (e.g. professional indemnity, public liability) is required for registration or only practical for operating **[Verify]**
- [ ] Record outcome/confirmation letters in `05_Insurance-Financial/`

## Phase 3 – Pre-lodgement QA
- [ ] Walk the document register line by line: every row Status = Ready
- [ ] Second person reads the whole pack cold and logs queries
- [ ] Names, dates, addresses, licence numbers consistent everywhere
- [ ] All certification/witnessing is current and legible
- [ ] Scans are legible, correctly oriented, within file size limits; one PDF per document, sensible names
- [ ] Backup copy of the complete pack stored in `07_Application-Submission/`

## Phase 4 – Lodgement
- [ ] Lodge via the BPC online portal **[Verify]**
- [ ] Pay fees; save receipt and application reference number
- [ ] Diary a weekly check of email (including spam) for BPC requests
- [ ] Save the submitted application as a PDF snapshot

## Phase 5 – Assessment
- [ ] Booking confirmation saved; ID requirements for the exam noted
- [ ] Syllabus / reference list confirmed (BCA/NCC volumes, Building Act 1993, Building Regulations 2018, contracts, insurance, WHS) **[Verify]**
- [ ] Timed practice using the study app in this repo
- [ ] Exam sat; result saved

## Phase 6 – Decision
- [ ] Registration certificate/number saved; conditions read
- [ ] Domestic building insurance arranged as required before taking domestic work **[Verify]**
- [ ] Register entry checked for accuracy

## Phase 7 – Post-registration
- [ ] CPD obligations and log set up
- [ ] Renewal date and fee in calendar (with two reminders)
- [ ] Contract templates compliant with the Domestic Building Contracts Act 1995 reviewed by a lawyer
- [ ] Business structure, ABN, GST, workers compensation, public liability as relevant
